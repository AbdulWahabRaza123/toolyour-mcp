# Content Refresh Skill

When refreshing **blog or landing page content**:

1. Crawl or fetch page text via API-backed tools.
2. Use AI text tools (`discover_tools("ai text")`) for rewrite suggestions.
3. Compare against SEO metadata tools if available.
4. Deliver: gaps, updated outline, and suggested meta title/description.
